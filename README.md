# 🕷️ مجموعة مشاريع Python Web Scraping

مجموعة من مشاريع **Web Scraping** واستخراج البيانات من **APIs** باستخدام لغة Python، تهدف إلى جمع البيانات ومعالجتها وتنقيتها وتنظيمها وتصديرها إلى عدة صيغ يمكن استخدامها في التحليل أو التطبيقات المختلفة.

يحتوي المشروع على تطبيقات عملية للتعامل مع صفحات الويب وواجهات API، بالإضافة إلى التعامل مع الصفحات المتعددة، معالجة الأخطاء، تصفية البيانات، وحفظ النتائج بصيغ مختلفة.

---

## 🚀 مميزات المشروع

- **Web Scraping:** استخراج البيانات من صفحات الويب باستخدام BeautifulSoup.
- **استخراج البيانات من APIs:** إرسال Requests ومعالجة البيانات القادمة بصيغة JSON.
- **معالجة الأخطاء:** التعامل مع أخطاء الاتصال، انتهاء مهلة الطلبات، وفشل استجابات API.
- **تصفية البيانات:** تطبيق شروط مخصصة لتصفية البيانات حسب السعر والتقييم والتوافر.
- **دعم Pagination:** الانتقال بين الصفحات تلقائيًا لجمع بيانات من أكثر من صفحة.
- **تصدير البيانات:** حفظ البيانات بصيغ CSV وJSON وExcel وTXT.
- **معالجة البيانات:** استخدام Pandas لتنظيم ومعالجة البيانات المستخرجة.

## 📌 طريقة الاستخدام

### 1. برنامج استخراج بيانات API

الملف:

```text
javascript_json_scraper.py
```

يقوم البرنامج بجلب البيانات من واجهة API بصيغة JSON، ثم تطبيق شروط التصفية على البيانات وتصدير النتائج إلى ملفات CSV وJSON.

لتشغيل البرنامج:

```bash
python javascript_json_scraper.py
```

---

### 2. برنامج Web Scraping للكتب

الملف:

```text
scraper.py
```

يقوم البرنامج بالتنقل بين صفحات متجر إلكتروني للكتب واستخراج مجموعة من البيانات، مثل:

- اسم الكتاب
- السعر
- حالة التوافر
- التقييم

ثم يتم حفظ البيانات المستخرجة بعدة صيغ.

لتشغيل البرنامج:

```bash
python scraper.py
```
